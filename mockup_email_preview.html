Executive Summary

  • Microsoft patched an actively exploited Windows kernel zero-day (CVE-2026-21001) used in targeted attacks; apply May Patch Tuesday updates immediately.
  • Cisco disclosed a Critical unauthenticated RCE in IOS XE WebUI (CVE-2026-20104, CVSS 10.0); disable WebUI on internet-facing devices until 17.12.4 is deployed.
  • Fortinet released emergency fixes for FortiManager (CVE-2026-39555, CVSS 9.8) with PoC code already public; restrict the FortiManager mgmt interface today.
  • Ivanti confirmed exploitation of Connect Secure VPN (CVE-2026-0282); apply 22.7R2.6 and run the Integrity Checker Tool.
  • Apple shipped iOS 18.5 with a fix for a WebKit zero-day (CVE-2026-23209) reportedly used against targeted individuals.
